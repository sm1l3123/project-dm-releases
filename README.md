# Mizena — стабильные сборки для Windows

**Mizena** — локальная программа для подготовки и проведения настольных ролевых игр: кампании, сцены, музыка, эмбиент, звуковые эффекты, материалы, браузерная консоль мастера и экраны игроков.

Этот **публичный репозиторий предназначен только для Windows-установщиков, описаний выпусков и метаданных обновления Stable**. Исходный код Mizena находится в отдельном закрытом репозитории.

## Установка

- [Скачать последнюю Stable](https://github.com/sm1l3123/project-dm-releases/releases/latest).
- [Посмотреть все Stable-выпуски](https://github.com/sm1l3123/project-dm-releases/releases).
- [Экспериментальные Open Beta](https://github.com/sm1l3123/project-dm-beta-releases/releases) публикуются отдельно.

Откройте последнюю Stable и скачайте установщик с именем `mizena-<версия>-setup.exe`. Файлы `latest.yml` и `.blockmap` нужны встроенной системе обновления, скачивать их вручную не требуется.

После установки приложение сообщает о доступных обновлениях. Их установка добровольна: можно закрыть уведомление и продолжить игру.

## Данные и переход между версиями

- Кампании, заметки, аудиотека и материалы хранятся отдельно от установленного исполняемого файла.
- Stable и Beta используют общую рабочую папку `Documents\Mizena`. **Не запускайте их одновременно с одной рабочей папкой** и делайте резервную копию перед переходом на экспериментальную Beta.
- При первом переходе со старого Project DM предусмотрено безопасное копирование из `Documents\Project DM`, когда `Documents\Mizena` ещё не существует. Старые данные не удаляются; автоматического объединения разных существующих папок нет.
- При возврате со свежей Beta на старую Stable может оказаться, что формат данных более новый. Сделайте резервную копию и не пытайтесь открывать новые данные старым приложением для записи.

## Обратная связь

При сообщении об ошибке укажите версию Mizena, версию Windows и последовательность действий, после которых возникла проблема.

Исторический адрес репозитория содержит `project-dm` ради совместимости канала обновлений. Актуальное имя продукта — **Mizena**.
