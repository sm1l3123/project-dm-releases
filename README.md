# Project DM — установщики и обновления

Project DM — приложение для подготовки и проведения настольных ролевых игр: музыка, эмбиент, звуки, пульт мастера и экраны игроков.

**Текущий этап: альфа-тестирование.**

[Скачать последнюю версию для Windows](https://github.com/sm1l3123/project-dm-releases/releases/latest)

## Установка

Скачайте project-dm-0.5.0-setup.exe из выпуска 0.5.0, закройте приложение и запустите установщик. Можно устанавливать поверх предыдущей версии: кампании и аудиотека хранятся отдельно.

Для перехода с 0.4.x нужно один раз установить 0.5.0 вручную. Начиная с 0.5.0, приложение проверяет новые выпуски при запуске и позволяет обновиться по кнопке. Обновление добровольное: уведомление можно закрыть и продолжить игру.

В этом репозитории размещаются установщики, описания выпусков и файлы канала обновлений. Загрузки альфа-версии сейчас общедоступны.

При сообщении об ошибке укажите версию Project DM, версию Windows и шаги воспроизведения.
